ArduinoRemote

ESP32-C3 SuperMini • Bluetooth Low Energy • Forward / Back remote control

ArduinoRemote is a tiny BLE remote-control firmware for the ESP32-C3 (SuperMini). Two physical buttons — Forward and Back — send single-character commands over Bluetooth Low Energy to a phone, tablet, or computer. The same commands can be sent to the board over BLE, so a host can drive it remotely too.

Two buttons

Forward and Back, each debounced in firmware. Status LED flashes on every press.

BLE

Advertises as ArduinoRemote. Works with the Web Bluetooth controller below, nRF Connect, or any BLE central.

No extra hardware

Uses the ESP32-C3's built-in BLE radio. Buttons wire straight to GND (internal pull-ups).

1. Try the controller (Web Bluetooth)

Open the controller page, tap Connect, and choose ArduinoRemote from the device picker. Then press Forward / Back — the board will flash its LED and echo the command back.

Web Bluetooth requires a secure context: serve over HTTPS (GitHub Pages works) or run on localhost.

2. Wire it up

Change the pins at the top of firmware/ArduinoRemote/ArduinoRemote.ino if your board uses different GPIOs.

3. Flash the firmware

Install the Arduino CLI, then:

$ arduino-cli core update-index
$ arduino-cli core install esp32:esp32
$ arduino-cli compile --fqbn esp32:esp32:makergo_c3_supermini firmware/ArduinoRemote
$ arduino-cli upload -p COM3 --fqbn esp32:esp32:makergo_c3_supermini firmware/ArduinoRemote

Board: MakerGO ESP32 C3 SuperMini (esp32:esp32:makergo_c3_supermini). Any ESP32-C3 board works — just pick its FQBN instead. Replace COM3 with your serial port (/dev/cu.usbmodem... on Mac, /dev/ttyUSB0 on Linux).

Prefer the Arduino IDE? Open firmware/ArduinoRemote/ArduinoRemote.ino, select your ESP32-C3 board and port, then click Upload.

4. BLE protocol

UUIDRolePropertiesValues
7f4f1234-1234-1234-1234-123456789abcService——
7f4f1235-1234-1234-1234-123456789abcRX (host → ESP32)WRITE, WRITE_NRF Forward • B Back • S Stop
7f4f1236-1234-1234-1234-123456789abcTX (ESP32 → host)NOTIFYEcho of the command just received

Example (Web Bluetooth): write a single byte 0x46 ('F') to the RX characteristic; the ESP32 notifies back 0x46 on the TX characteristic.
